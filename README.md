# Spendly Backend

Бэкенд-часть приложения Spendly — голосового трекера расходов. 
Пользователь надиктовывает или пишет фразу (например, «сегодня оставил пятихатку на шаурму»), а система с помощью языковой модели извлекает суммы и распределяет их по категориям, в данном случае 500 рублей на еду.

## Стек технологий
* **Язык:** Python 3.10+
* **Фреймворк:** FastAPI
* **База данных:** SQLite (на этапе MVP), SQLAlchemy (ORM)
* **Нейросеть:** GigaChat API (для парсинга фраз и советов)
* **Авторизация:** JWT (JSON Web Tokens)

## Основные эндпоинты (в разработке)
* `POST /auth/register` — регистрация пользователя
* `POST /auth/login` — авторизация и получение токена
* `POST /transactions/parse` — отправка текста/голоса на парсинг нейросетью
* `GET /transactions` — получение списка трат
* `GET /stats` — получение статистики за период
* `POST /goals` — создание финансовой цели

## Как запустить локально (для команды)
1. Клонировать репозиторий:
   `git clone https://github.com/твой_ник/spendly-backend.git`
2. Создать виртуальное окружение:
   `python -m venv venv`
3. Активировать его:
   * Windows: `venv\Scripts\activate`
   * Mac/Linux: `source venv/bin/activate`
4. Установить зависимости:
   `pip install fastapi uvicorn sqlalchemy`
5. Запустить сервер:
   `uvicorn main:app --reload`
6. Открыть Swagger-документацию в браузере: `http://127.0.0.1:8000/docs`
