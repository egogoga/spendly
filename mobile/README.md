# Spendly — заготовка приложения на Flutter

Учёт расходов голосом: говоришь «оставил пятихатку на шаурму» — приложение само находит сумму и категорию.
В проекте свёрстаны все 7 экранов из макета, голос уже распознаётся по-настоящему, а вместо сервера пока работают заглушки.

Инструкция рассчитана на тех, кто открывает Flutter впервые. Команды одинаковые для Windows и macOS, различия отмечены отдельно.

---

## 1. Установить инструменты (один раз)

1. **Git.** Windows: https://git-scm.com/downloads/win — установить со всеми настройками по умолчанию.
   macOS: в «Терминале» выполнить `xcode-select --install`.
2. **Visual Studio Code** — https://code.visualstudio.com
3. **Google Chrome** — если его ещё нет. В нём удобнее всего запускать приложение первый раз.
4. **Расширение Flutter в VS Code.** Откройте VS Code → `Ctrl+Shift+X` (на Mac `Cmd+Shift+X`) → найдите **Flutter** → **Install**. Расширение Dart установится вместе с ним.
5. **Сам Flutter.**
   - `Ctrl+Shift+P` → начните печатать `flutter` → выберите **Flutter: New Project**.
   - VS Code скажет, что не нашёл Flutter SDK → нажмите **Download SDK**.
   - Выберите папку, куда его положить, например `C:\dev`, и нажмите **Clone Flutter**. Загрузка займёт несколько минут.
   - Когда появится кнопка **Add SDK to PATH** — нажмите её.
   - Закройте и снова откройте VS Code.

   > ⚠️ В пути к Flutter и к проекту не должно быть русских букв и пробелов. `C:\dev\flutter` — хорошо, `C:\Users\Саша\Мои проекты` — плохо: сборка под Android может сломаться.
6. **Проверка.** В VS Code: меню **Terminal → New Terminal**, введите:
   ```
   flutter doctor
   ```
   Достаточно зелёных галочек у **Flutter** и **Chrome**. Жёлтые и красные пункты про Android Studio, Xcode и Visual Studio пока можно не трогать.

## 2. Первый запуск — в браузере

1. Распакуйте архив, например в `C:\dev\spendly`.
2. VS Code → **File → Open Folder** → выберите папку `spendly`.
3. **Terminal → New Terminal** и выполните три команды по очереди:
   ```
   flutter create --project-name spendly --platforms android,ios,web .
   dart run tool/setup_platforms.dart
   flutter run -d chrome
   ```
   - Первая команда досоздаёт служебные папки `android`, `ios`, `web`. Наш код она не трогает. Точка в конце означает «в этой папке».
   - Вторая добавляет разрешения на микрофон и распознавание речи.
   - Третья собирает приложение и открывает его в Chrome. Первый раз это может занять пару минут.
4. В приложении: **Войти** (подойдут любые данные, сервер пока не нужен) → чёрная кнопка с микрофоном → разрешите доступ к микрофону → скажите фразу → **Готово** → проверьте траты → **Сохранить**.

### Как менять код и сразу видеть результат
Пока приложение запущено, в терминале работают клавиши:
- `r` — быстро перезагрузить изменения (hot reload), состояние сохранится;
- `R` — перезапустить приложение целиком;
- `q` — остановить.

Можно запускать и кнопкой **F5** в VS Code — тогда изменения подхватываются при каждом сохранении файла.

> Голос в браузере работает в Chrome и Edge. В Firefox распознавания речи нет — приложение подставит пример фразы.

## 3. Запуск на Android-телефоне

1. Установите **Android Studio**: https://developer.android.com/studio
2. Откройте её → **More Actions → SDK Manager**:
   - вкладка **SDK Platforms** — отметьте самую новую версию Android, нажмите **Apply**;
   - вкладка **SDK Tools** — отметьте **Android SDK Build-Tools**, **Android SDK Command-line Tools**, **Android Emulator**, **Android SDK Platform-Tools**, **CMake**, **NDK (Side by side)** → **Apply**.
3. В терминале VS Code примите лицензии (на все вопросы отвечайте `y`):
   ```
   flutter doctor --android-licenses
   ```
4. На телефоне: **Настройки → О телефоне** → 7 раз нажмите на **Номер сборки** → появится раздел **Для разработчиков** → включите там **Отладку по USB**.
5. Подключите телефон кабелем и разрешите на нём отладку для этого компьютера. На Windows для некоторых телефонов нужен USB-драйвер производителя.
6. Проверьте и запустите:
   ```
   flutter devices
   flutter run
   ```
   Если устройств несколько, Flutter попросит выбрать номер. Первая сборка под Android долгая (5–15 минут): Gradle скачивает всё нужное. Потом сборка идёт быстро.

**Эмулятор вместо телефона:** Android Studio → **More Actions → Virtual Device Manager** → **+** → выберите телефон и образ системы → **Finish** → кнопка ▶. Но микрофон в эмуляторе работает не всегда, поэтому голос лучше проверять на настоящем телефоне.

> Распознавание речи на Android работает через сервисы Google. На телефонах без них (часть Huawei и Honor) приложение подставит пример фразы.

## 4. iPhone

Собрать приложение для iPhone можно только на Mac с установленным Xcode: подключите iPhone и выполните `flutter run`. Подробнее: https://docs.flutter.dev/platform-integration/ios/setup

## Как устроен проект

```
lib/
  main.dart                 — точка входа, тема, первый экран
  theme.dart                — цвета и шрифты из макета
  data/
    models.dart             — трата, категория, цель, статистика
    api.dart                — запросы к серверу (сейчас — заглушка)
    phrase_parser.dart      — демо-разбор фраз и подсветка сумм
    expense_store.dart      — траты в памяти, экраны обновляются от него
    mock_data.dart          — тестовые данные
    format.dart             — «23 410 ₽», «Вторник, 10 ноября», склонения
  widgets/
    common.dart             — карточки, кнопки, нижнее меню, полоски прогресса
  screens/
    auth_screen.dart        — вход и регистрация
    shell.dart              — нижнее меню и кнопка микрофона
    home_screen.dart        — главная
    listening_screen.dart   — голосовой ввод
    parsed_screen.dart      — проверка распознанных трат
    history_screen.dart     — история с поиском и фильтрами
    stats_screen.dart       — статистика за день / неделю / месяц
    goals_screen.dart       — лимиты и цели
tool/setup_platforms.dart   — добавляет разрешения на микрофон
test/widget_test.dart       — проверки разборщика фраз (запуск: flutter test)
```

### Что работает, а что пока заглушка

| Работает по-настоящему | Заглушка |
|---|---|
| Все 7 экранов и переходы между ними | Вход пускает с любыми данными |
| Голос → текст (встроенное распознавание телефона или браузера) | Разбор фраз — простой разборщик внутри приложения вместо GigaChat |
| Подсветка сумм, «Уже понял», правка категории и суммы | Статистика и цели — тестовые цифры |
| Сохранение, история, поиск и фильтры | Данные пропадают после перезапуска |

## Подключение сервера (FastAPI)

Когда сервер будет готов, откройте `lib/data/api.dart` и поменяйте две строки:
```dart
static String baseUrl = 'http://localhost:8000'; // адрес сервера
static bool useMock = false;                     // выключить заглушку
```

Приложение отправляет такие запросы (JSON):

| Запрос | Что отправляет приложение | Что ждёт в ответ |
|---|---|---|
| `POST /auth/register` | `{"name", "email", "password"}` | `{"access_token": "..."}` |
| `POST /auth/login` | `{"email", "password"}` | `{"access_token": "..."}` |
| `POST /expenses/parse` | `{"text": "оставил пятихатку на шаурму"}` | `{"items": [{"title": "Шаурма", "category": "food", "amount": 500, "source": "пятихатку", "phrase": "оставил пятихатку на шаурму"}]}` |
| `POST /expenses` | `{"items": [{"title", "category", "amount", "date", "phrase"}]}` | любой ответ с кодом 200 |

- Коды категорий: `groceries`, `food`, `transport`, `cafe`, `subs`, `other`.
- После входа приложение добавляет заголовок `Authorization: Bearer <access_token>`.
- `/expenses/parse` только разбирает фразу через GigaChat и ничего не сохраняет: сохранение происходит после того, как пользователь проверил траты.
- Ключ GigaChat храните только на сервере, в приложение его не добавляйте.
- Чтобы приложение в Chrome могло обращаться к серверу, в FastAPI нужно включить CORS (`CORSMiddleware`).
- Адрес сервера для разных случаев: Chrome на том же компьютере — `http://localhost:8000`, эмулятор Android — `http://10.0.2.2:8000`, настоящий телефон — `http://<IP компьютера в Wi-Fi сети>:8000`.

## Частые проблемы

- **«flutter не является внутренней или внешней командой».** Перезапустите VS Code (иногда и компьютер). Если не помогло — повторите шаг 5 из раздела 1 и не забудьте нажать **Add SDK to PATH**.
- **`flutter run -d chrome` пишет, что устройство не найдено.** Установите Chrome или запустите в Edge: `flutter run -d edge`.
- **Сборка под Android падает с непонятной ошибкой про путь.** Скорее всего, в пути к проекту есть русские буквы или пробелы. Перенесите папку в `C:\dev\spendly`.
- **Шрифты выглядят как обычные системные.** При первом запуске шрифты скачиваются из интернета. Проверьте подключение и перезапустите приложение.
- **Микрофон не работает в Chrome.** Нажмите на значок слева от адреса страницы и разрешите доступ к микрофону.
